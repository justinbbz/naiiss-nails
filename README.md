# Naiiss Nails · maquette de démonstration

Maquette **non officielle** du site de Naiiss Nails (prothésiste ongulaire à Forcalquier), réalisée pour présenter une idée de site : film d'un ongle qui reçoit du vernis et qui avance avec le défilement, réservation avec acompte, cartes cadeau, avis, créations.

- **Démonstration** : aucun rendez-vous n'est enregistré, aucun paiement n'est effectué, les tarifs sont indicatifs.
- Non indexée par les moteurs de recherche.
- Le film d'accueil est généré par intelligence artificielle ; les photos des créations viennent du compte Instagram public @naiiss.nails (à remplacer par les originaux).
- Site statique (HTML, CSS, JavaScript), sans dépendance.
